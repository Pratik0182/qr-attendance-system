🚀 Our Mission

Traditional paper-based attendance is slow, error-prone, and trivially exploitable — any student can sign for an absent friend in seconds. We set out to build a system that makes proxy attendance physically and mathematically impossible. The result is a platform that combines cryptographically signed, time-bound QR codes with subnet-level Wi-Fi network validation and session-aware role-based access control. Every scan is verified against three independent axes: time (is the QR still valid?), network (is the device on the classroom Wi-Fi?), and identity (is the session authenticated?). Miss any one of them and attendance is rejected. No workarounds. No loopholes.

⚔️ Problem vs. Solution

❌ Before — The Old Way

  • Paper registers: friends sign for each other
  • Manual data entry errors and lost sheets
  • No real-time attendance visibility
  • Teachers can't verify identity on the spot
  • Static screenshots of QR codes shared on WhatsApp
  • No audit trail or tamper detection
  • Percentage calculations done manually in Excel

✅ After — Our System

  • QR changes every 60 s — screenshots are useless
  • HMAC signature — forging a token is infeasible
  • Real-time dashboard updated per scan
  • Session-bound login — no anonymous access
  • Subnet check — must be on classroom Wi-Fi
  • Full DB audit trail per student per date
  • Live percentage charts updated automatically
⚙️ How It Works
1
Teacher Logs In
Selects course, chooses date, sets QR validity window (60–300 s)
2
QR Generated
Server signs a token with HMAC-SHA256 containing timestamp, IP & course code
3
Student Scans
In-browser camera (jsQR) reads the code — no third-party app needed
4
Triple Validation
Server checks expiry, CIDR subnet match, and token signature simultaneously
5
DB Updated
Attendance record committed — visible instantly on teacher dashboard
✨ Key Features
🔐
HMAC-SHA256 Signed Tokens
Every QR payload is signed with a server-side secret. Tampered or forged tokens are rejected instantly — no exceptions.
🌐
CIDR Subnet Validation
Uses Python's ipaddress module for precise /24 subnet matching. Students must be on the same classroom Wi-Fi as their teacher.
⏱️
Time-Bound QR Codes
QR codes expire in as little as 60 seconds. A screenshot shared on WhatsApp is already dead by the time it's opened.
👩‍🏫
Role-Based Access Control
Teachers generate QRs and view all records. Students can only see their own attendance — IDOR vulnerabilities are structurally impossible.
📋
Manual Attendance Override
Teachers can correct any date's attendance manually — medical leaves, system issues, and edge cases all handled gracefully.
📅
Live Attendance History
Students see a per-subject attendance breakdown with exact counts, percentages, and colour-coded date history.
📸
No App Required
QR scanning runs fully in-browser via jsQR and the WebRTC Camera API. Students just open the website — nothing to install.
🌙
Dark / Light Mode
A polished theme toggle with localStorage persistence. Your preference is remembered across sessions and pages.
🛡️
bcrypt Password Hashing
All credentials are stored as bcrypt hashes with salting. Even a full DB dump reveals nothing useful to an attacker.
